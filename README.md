# 小小汉字 · 每日认字

面向亲子识字检查的静态页面，支持按组按顺序认字、中文朗读、隐藏提示、每日检查记录和 JSON 备份。

内置 13 组、126 个字位（重复字按原顺序保留）。现有浏览器中的字表会自动追加第 9～13 组，保留已有检查结果。

## 本地使用

在仓库根目录运行 `python -m http.server 5187 --bind 127.0.0.1`，然后访问 http://127.0.0.1:5187/ 。无需安装依赖或构建。网站入口及资源均在仓库根目录。

运行 `node check.cjs` 检查字表顺序、每日记录、顺序检查、备份校验和旧记录迁移。

记录保存在当前浏览器的本地存储，不会上传 GitHub。换设备前可在“管理字表与备份”导出记录。朗读依赖浏览器和设备提供的中文语音。
